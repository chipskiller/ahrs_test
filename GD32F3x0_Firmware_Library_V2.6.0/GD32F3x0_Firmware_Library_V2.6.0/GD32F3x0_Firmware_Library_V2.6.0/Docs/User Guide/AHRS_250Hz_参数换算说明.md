## 1. 当前运行状态与"单一配置源"设计

所有与采样率相关的参数，统一由 **`main.h` 里的一个宏**派生，改频率只需改一处：

```c
#define SAMPLING_FREQ_HZ  1000.0f         /* ← 唯一需要修改的频率参数 */
#define SAMPLING_PERIOD_S (1.0f / SAMPLING_FREQ_HZ) /* 采样周期(秒) */
#define DT                SAMPLING_PERIOD_S         /* DT = 采样周期 */
```

由它派生的宏：

| 宏 | 当前值 | 含义 |
|----|:---:|------|
| `DT` | 0.001 s | 采样周期 |
| `FRAMES_PER_SEC` | 1000 | 每秒帧数 |
| `FRAMES_100MS` | 100 | 100ms 对应帧数 |
| `FRAMES_5S` | 5000 | 5s 对应帧数 |
| `FRAMES_30S` | 30000 | 30s 对应帧数 |

## 3. τ（时间常数）：统一收敛速度的度量

### 3.1 是什么

τ 是一阶低通滤波（指数滑动平均 EMA）的**时间常数**，代表"滤波器记忆时长 / 收敛速度"。τ 小 → 收敛快、跟随快但易被噪声骗；τ 大 → 收敛慢、抗干扰强但反应迟钝。

### 3.2 怎么算：α = DT/τ

零偏更新用 EMA：$b_k = (1-\alpha)b_{k-1} + \alpha\,gz_k$，其中：

$$\alpha = \frac{DT}{\tau} = \frac{1}{f \cdot \tau}$$

它由连续低通滤波器 $H(s)=1/(1+\tau s)$ 离散化而来——要让每帧都按同一指数衰减，每帧只吸收 $\alpha=DT/\tau$ 的比例。**想设某个收敛速度 τ，就用 α=DT/τ**。

### 3.3 数值含义

经过 τ 秒，估计值向真实值移动约 **63%**（1−1/e）；经过 **3τ** 秒约 **95%**。所以 τ=10s 意味着收敛要几十秒——这是"晃停后飘几十秒才停"的原因。

### 3.4 当前代码的 τ 家族

| 机制 | τ | 作用 |
|------|:---:|------|
| 零偏慢修（稳态） | 3s | 长期慢速跟踪零偏 |
| 零偏快修（温度突变） | 0.1s | 温度变化快速追上 |
| 零偏重收敛（刚静止前5s） | 1s | 晃动后快速回零 |
| Mahony Kp | 1/5 = 0.2s | pitch/roll 静止后拉平 |
| 积分项衰减 | ≈2s | 运动时积分项泄放 |

**规律**：τ 是"目标"（设计值），α 是"实现"（随采样率变，α=DT/τ）。这就是它在各换算表中反复出现的原因。

## 4. 零偏自校准机制（三档收敛）

### 4.1 静止检测的防死锁设计

- 用**原始陀螺值** + **温度自适应阈值**判静止，保证静止设备不会因温漂零偏被误判为运动（避免"零偏误差大 → 永不判静止 → 零偏永不更新"的死锁）
- 新增**加速度模长≈1g** 辅助判定，防止轻微晃动（低于陀螺阈值）被当成静止而污染零偏

### 4.2 三档收敛

```c
if (stable_cnt > FRAMES_5S) {        /* 静止≥5s 才开始更新零偏 */
  if (temp_diff_flag)      alpha = alpha_fast;   /* τ=0.1s 温度突变 */
  else if (stable_cnt < FRAMES_5S*2) alpha = DT/1.0f;  /* τ=1s 快速重收敛 */
  else                     alpha = alpha_slow;   /* τ=3s 稳态跟踪 */
}
```

- **5s 门限**：确保确实静止
- **前 5s τ=1s**：晃动停止后快速抵消残差，yaw 漂移明显缩短
- **之后 τ=3s**：长期慢速跟踪温度漂移
- **温度突变 τ=0.1s**：快速响应温漂

### 4.3 yaw 必须无条件积分

```c
att.yaw_now += gz_comp * DT;   /* 每帧执行，不受静止状态冻结 */
```

若把 yaw 积分放在 `else` 分支（静止时冻结），会：① 缓慢真实旋转被丢掉；② 漂移被"藏起来"而非消除，重新运动时留下错误值。

## 6. ICM42670 传感器寄存器配置（当前 1000Hz 目标）

### 6.1 访问方式

配置的寄存器（PWR_MGMT0 / GYRO_CONFIG0 / ACCEL_CONFIG0 / GYRO_CONFIG1 / ACCEL_CONFIG1）均位于 **Bank0**，**直接寻址**，无需 MREG 间接访问。

仅 MREG1/2/3 扩展寄存器需要间接流程（BLK_SEL_W → MADDR_W → M_W → 等10µs，用后清零）。

### 6.2 最终配置（软 I2C 初始化写入）

| 寄存器 | 地址 | 写入值 | 含义 |
|--------|:---:|:---:|------|
| PWR_MGMT0 | 0x1F | 0x00 → 0x0F | 上电 → 陀螺/加速度 LN 低噪声模式 |
| GYRO_CONFIG0 | 0x20 | **0x65** | ±250dps + ODR **1.6kHz** |
| ACCEL_CONFIG0 | 0x21 | **0x65** | ±2g + ODR **1.6kHz** |
| GYRO_CONFIG1 | 0x23 | 0x34 | 陀螺低通滤波 **53Hz** |
| ACCEL_CONFIG1 | 0x24 | 0x44 | 加速度低通滤波 **53Hz** |

### 6.3 位分解

`0x65 = 0b0110 0101`：bits[6:5]=`11`→量程 ±250dps/±2g；bits[3:0]=`0101`→ODR 1.6kHz

`0x34 = 0b0011 0100`：bits[2:0]=`100`→LPF 53Hz，保留位保持复位值

`0x44 = 0b0100 0100`：bits[2:0]=`100`→LPF 53Hz，bits[6:4]（AVG）保持复位值

### 6.4 为什么这样配

- **ODR 1.6kHz**：1000Hz 采样要求 ODR ≥ 1000Hz；手册无 1kHz 档，1.6kHz（`0101`）最近且留 1.6 倍余量，每帧均为新数据
- **滤波 53Hz**：灯杆慢速倾斜场景，低通显著压噪；53Hz < ODR/2=800Hz 无混叠；比默认 180Hz 平滑，代价是轻微响应滞后
- **LN 模式**：陀螺+加速度同时低噪声

### 6.5 速查表（Bank0）

ODR（GYRO_CONFIG0 / ACCEL_CONFIG0 bits[3:0]）：

| 编码 | GYRO_ODR | ACCEL_ODR |
|:---:|:---:|:---:|
| 0101 | 1.6 kHz | 1.6 kHz (LN) |
| 0110 | 800 Hz | 800 Hz (LN) |
| 0111 | 400 Hz | 400 Hz |
| 1000 | 200 Hz | 200 Hz |
| 1001 | 100 Hz | 100 Hz |
| 1010 | 50 Hz | 50 Hz |
| 1011 | 25 Hz | 25 Hz |

滤波带宽（GYRO_CONFIG1 / ACCEL_CONFIG1 bits[2:0]）：

## 7. 时间预算与对策（1000Hz）

1000Hz 单帧预算仅 **1ms**。当前主要耗时估算：

| 项 | 耗时（I2C 400kHz） |
|----|:---:|
| I2C 读 IMU（14B） | ~0.4ms |
| I2C 读磁力计（6B） | ~0.15ms |
| 姿态解算 | ~0.3ms |
| **合计** | **~0.85ms** ⚠️ |

余量约 0.15ms，可能抖动超时。若实测超 1ms，对策（按优先级）：

1. **磁力计降频读取**：6 轴模式磁力计仅用于干扰检测（本就每100ms一次），可每 5~10 帧读一次
2. **合并温度读取**：温度(0x09,2B)与数据(0x0B,12B)合并为一次 14B 读，省一个 I2C 事务
3. 降频解算（如采样1kHz、解算500Hz，读传感器1kHz）

## 附录 A：频率换算原理（历史推导，以 250Hz 为例）

### A.1 换算基准

$$f_{old}=100,\ f_{new}=250,\ R=\frac{f_{new}}{f_{old}}=2.5,\ DT_{new}=\frac{1}{f_{new}}$$

### A.2 通用换算

- **帧数阈值**：$N_{new} = N_{old} \times R$（帧数 = 墙钟时间 × 频率）
- **EMA 系数**：$\alpha_{new} = \alpha_{old} \times \dfrac{1}{R}$（保持 τ 不变）
- **Ki**：$Ki_{new} = Ki_{old} \times \dfrac{1}{R}$（保持每秒积分速率）
- **积分衰减**：$k_{new} = k_{old}^{\,1/R}$（保持每秒衰减）
- **Kp**：不变（τ=1/Kp 与采样率无关）

### A.3 通用速查（含当前 1000Hz）

设 $f_{old}=100$，目标频率为 $f$：

| 参数 | 公式 | 300Hz | 500Hz | **1000Hz** |
|------|------|:---:|:---:|:---:|
| DT | 1/f | 0.003333 | 0.002 | **0.001** |
| 帧数阈值 | × f/100 | ×3 | ×5 | **×10** |
| 慢修 α（τ=3s） | (1/f)/3 | 0.00111 | 0.000667 | **0.00033** |
| 快修 α（τ=0.1s） | (1/f)/0.1 | 0.033 | 0.02 | **0.01** |
| Ki | 0.003×100/f | 0.001 | 0.0006 | **0.0003** |
| 积分衰减 k | 0.995^(100/f) | 0.9983 | 0.999 | **0.9995** |
| Kp | 不变 | 5.0 | 5.0 | **5.0** |

## 附录 B：关键推导

### B.1 EMA 时间常数 τ = DT/α

一阶低通 $y_k=(1-\alpha)y_{k-1}+\alpha x_k$，脉冲响应衰减到 $1/e$ 需 $\tau=DT/\alpha$ 秒。

### B.2 Kp 与采样率无关

修正项 $dq=(e\cdot Kp)\cdot(DT/2)$，角度增量 $\Delta\theta=2\,dq=e\cdot Kp\cdot DT$，每秒 $d\theta/dt=e\cdot Kp\approx Kp\cdot\theta$ → τ=1/Kp，与 DT 无关。

### B.3 积分衰减换算

"每秒衰减"与频率无关：$k_{old}^{f_{old}} = k_{new}^{f_{new}}$ → $k_{new}=k_{old}^{f_{old}/f_{new}}$。
