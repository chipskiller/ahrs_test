## 三、推荐阅读路线

### 新手 / 想建立整体认知
1. **上电启动流程与原理详解.md** — 先把"程序怎么跑起来"的骨架建立起来
2. **Bootloader跳转调试总结.md** — 看实际踩坑案例，加深对跳转的理解
3. **硬件I2C调试总结.md** — 了解传感器读写链路
4. **姿态解算路径.MD** — 了解业务算法方向

### 遇到具体故障
| 现象 | 先查哪篇 |
|---|---|
| 跳转/启动相关（HardFault、卡死、printf 异常） | `Bootloader跳转调试总结.md` |
| 概念不清（SystemInit、Thumb、向量表） | `上电启动流程与原理详解.md` |
| I2C 读不到器件 / 超时 | `硬件I2C调试总结.md` |
| OTA 收发异常 / 串口收不到大帧 / F1 无回复 | `OTA串口接收调试总结.md` |
| 算法/融合相关问题 | `姿态解算路径.MD` |

## 四、文档维护约定

1. **命名**：中文描述性命名（如 `xxx调试总结.md` / `xxx原理详解.md`）。
2. **风格**：与现有文档保持一致——表格化、分层级、附实际代码、附 mermaid 流程图。
3. **结构**：排障类建议含「问题速查表（现象/根因/解决） + 详解 + 排障方法学」；原理类建议按「是什么/怎么做/为什么」展开。
4. **更新**：每次新增/大改后，回到本 README 更新索引表。
5. **通用概念**：涉及系统启动、指令集等通用知识的原理，优先放「原理篇」；具体一次性的排障，放「排障记录」。
