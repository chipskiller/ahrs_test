# AHRS 姿态解算采样率提升至 250Hz 参数换算说明

- 版本：V2.0.4_beta
- 日期：2026-08-17
- 适用文件：`Template/main.c`、`Template/flash.c`

---

## 1. 背景

原系统姿态解算主循环为 **100Hz**（`DT = 0.01s`，10ms 定时中断）。现提升至 **250Hz**（`DT = 0.004s`，4ms 定时中断）。

采样率提升后，**所有以"帧数"表示的时间阈值、以及所有按"采样率"标定的滤波参数**都必须同步换算，否则墙钟时长和滤波时间常数会发生 5 倍级偏差，导致行为错误。

---

## 2. 换算基准

$$f_{old} = 100\ \text{Hz},\quad f_{new} = 250\ \text{Hz},\quad R = \frac{f_{new}}{f_{old}} = 2.5$$

$$DT_{new} = \frac{1}{f_{new}} = \frac{1}{250} = 0.004\ \text{s}$$

---

## 3. 定时器配置（精确 250Hz）

系统时钟 84MHz，GD32F330 TIMER1。

```
预分频  prescaler = 8400 - 1  →  定时器时钟 = 84MHz / 8400 = 10kHz
重装载  period    = 40 - 1    →  中断频率   = 10kHz / 40   = 250Hz
周期                           =  40 × 0.1ms = 4ms
```

**为什么能整除**：250 是 10kHz 的约数（10000 / 250 = 40 是整数），因此无需改动预分频即可得到精确频率。

> 对比：若为 300Hz，10kHz / 300 = 33.33 不是整数，需要改预分频为 2800-1（→30kHz）再配 period=100-1。

---

## 4. 帧数阈值换算（×R = ×2.5）

所有"帧数"本质上代表**墙钟时间**（帧数 × DT = 时间）。频率提高后，同样时长对应更多帧，故帧数 × 2.5。

| 项 | 100Hz 值 | 250Hz 值 | 墙钟时长 | 换算 |
|----|:---:|:---:|:---:|------|
| 初始对准 `init_cnt >=` | 500 | **1250** | 5s | 500×2.5 |
| Mahony 门限 `stable_cnt >` | 10 | **25** | 100ms | 10×2.5 |
| 零偏更新门限 `stable_cnt >` | 500 | **1250** | 5s | 500×2.5 |
| 温度检测 `temp_stable_cnt %` | 3000 | **7500** | 30s | 3000×2.5 |
| 地磁检测 `loop_cnt %` | 10 | **25** | 100ms | 10×2.5 |
| 报警防抖 `× 100` | ×100 | **× 250** | 按秒 | ×2.5 |

**通用公式**：

$$N_{new} = N_{old} \times \frac{f_{new}}{f_{old}}$$

---

## 5. 滤波参数换算

### 5.1 零偏 EMA 慢/快修正系数 α

EMA 滤波器 $b_{k} = (1-\alpha)b_{k-1} + \alpha x_k$ 的**时间常数**为：

$$\tau = \frac{DT}{\alpha} = \frac{1}{\alpha \cdot f}$$

要**保持时间常数不变**，频率改变后 α 需反比缩放：

$$\alpha_{new} = \alpha_{old} \times \frac{f_{old}}{f_{new}} = \alpha_{old} \times \frac{1}{R}$$

| 项 | 100Hz 值 | 时间常数 τ | 250Hz 值 |
|----|:---:|:---:|:---:|
| 慢修 α | 0.001 | 0.01/0.001 = 10s | **0.0004** |
| 快修 α | 0.1 | 0.01/0.1 = 0.1s | **0.04** |

验算：$\alpha_{new} = 0.001 \times \frac{100}{250} = 0.0004$ ✓；$0.1 \times 0.4 = 0.04$ ✓

### 5.2 Mahony 比例增益 Kp（不变）

推导修正量等效旋转速率：

- 修正项：$dq_1 += (e_x \cdot Kp) \cdot half\_dt$，$half\_dt = DT/2$
- 由四元数"半角"关系：$\Delta\theta = 2 \cdot \Delta q_1 = e_x \cdot Kp \cdot DT$
- 每秒变化率：$\dfrac{d\theta}{dt} = e_x \cdot Kp \approx Kp \cdot \theta$（$e_x \approx \theta$）

即 **$\theta$ 以 $1/Kp$ 秒的时间常数指数衰减，与 DT 无关**。因此 **Kp 保持不变 = 5.0**（τ ≈ 0.2s）。

### 5.3 Mahony 积分增益 Ki

积分项 $i_x += e_x \cdot Ki$ 是**按帧累加**的，其每秒累加速率为：

$$\frac{di_x}{dt} = e_x \cdot Ki \cdot f$$

要**保持每秒速率不变**，Ki 需反比缩放：

$$Ki_{new} = Ki_{old} \times \frac{f_{old}}{f_{new}} = 0.003 \times \frac{100}{250} = 0.0012$$

### 5.4 运动时积分项衰减系数 k

运动时执行 $i_x *= k$（100Hz 时为 0.995）。**每秒**总衰减为 $k^{f}$（每秒乘 f 次）：

$$k_{100}^{100} = k_{250}^{250}$$

$$k_{250} = k_{100}^{\frac{100}{250}} = 0.995^{0.4} = e^{0.4 \ln 0.995} = e^{-0.00201} \approx 0.9980$$

### 5.5 汇总表

| 参数 | 100Hz | 250Hz | 保持量 | 换算方法 |
|------|:---:|:---:|:---:|------|
| `Kp` | 5.0 | **5.0（不变）** | τ=1/Kp=0.2s | 与采样率无关 |
| `Ki` | 0.003 | **0.0012** | 每秒积分速率 | × f_old/f_new |
| 慢修 α | 0.001 | **0.0004** | τ≈10s | α = DT/τ |
| 快修 α | 0.1 | **0.04** | τ≈0.1s | α = DT/τ |
| 积分衰减 k | 0.995 | **0.9980** | 每秒衰减≈0.605 | k_new = k_old^(f_old/f_new) |

## 6. 相关配套修正

### 6.1 `save_install_zero_point()` 采样节奏（flash.c）

标定循环原为 `500 帧 × delay_1ms(10)`（100Hz 节奏），但 `attitude_calc_6axis` 内部已用 `DT=0.004`。

若不同步，每帧只积分 4ms 却间隔 10ms → **yaw 积分快 2.5 倍**，存出的零位错误。

修正为与主循环一致：

```c
for (uint16_t i = 0; i < 1250; i++) {   // 250Hz × 5s
  ...
  delay_1ms(4);                          // 每帧 4ms，与 DT 匹配
}
att.yaw_base = yaw_sum / 1250.0f;        // 除数同步改为 1250
```

### 6.2 数据类型（main.c）

报警计数：`alarm_filter_cnt` / `alarm_time_max` 从 `uint16_t` 改为 `uint32_t`。

原因：250Hz 下 `alarm_warning_time × 250`，默认 180s × 250 = 45000 < 65535，但为防上限设置更大预警时间而溢出，改 32 位更安全。

## 8. 验证建议

1. **频率验证**：用 GPIO 翻转或 `printf` 时间戳确认主循环周期为 4ms
2. **时间预算**：250Hz 下单帧预算 4ms，实测 `imu_main_loop` 耗时（I2C 读取 + 姿态解算），若紧张可将硬件 I2C 提速到 400kHz 或降频磁力计读取
3. **行为验证**：静止零偏收敛时间（约 10s）、Mahony 静止后拉平时间（约 0.2s）、报警防抖时长、地磁检测周期是否与墙钟一致
4. **零位验证**：标定 → 断电重启 → 确认零位保留（修复后 `load_yaw_from_flash` 不再覆盖 `yaw_base`）

## 附录：关键推导

### A. EMA 时间常数 τ = DT/α

一阶低通：$y_k = (1-\alpha)y_{k-1} + \alpha x_k$

脉冲响应衰减到 $1/e$ 需 $\tau = DT/\alpha$ 秒。α 越大收敛越快，噪声跟随越强。

### B. Kp 与采样率无关

修正项作用于四元数增量：$dq = (e\cdot Kp)\cdot(DT/2)$

角度增量：$\Delta\theta = 2\,dq = e\cdot Kp\cdot DT$

每秒：$d\theta/dt = e\cdot Kp \approx Kp\cdot\theta$ → $\theta = \theta_0 e^{-Kp\,t}$，τ=1/Kp，与 DT 无关。

### C. 积分衰减换算

"每秒衰减"是频率无关的物理量：$k_{old}^{f_{old}} = k_{new}^{f_{new}}$

所以 $k_{new} = k_{old}^{f_{old}/f_{new}}$。
