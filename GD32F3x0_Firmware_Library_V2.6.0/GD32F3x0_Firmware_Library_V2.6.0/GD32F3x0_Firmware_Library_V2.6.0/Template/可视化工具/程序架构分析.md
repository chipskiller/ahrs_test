# visualize_6axis.py 程序架构分析

## 一、整体架构

程序分为 **三大模块**，通过 `main()` 函数串联：

```
┌─────────────────────────────────────────────────────────┐
│                      main() 入口                        │
│  命令行参数解析 → 文件解析 → 导出/绘图/列表              │
└────────────┬──────────────────┬─────────────────────────┘
             │                  │
     ┌───────▼───────┐  ┌──────▼──────┐  ┌──────────────┐
     │  协议解析模块  │  │ 交互式可视化 │  │  数据导出模块 │
     │  parse_file() │  │ build_figure │  │ export_data()│
     │  parse_frame()│  │ VOFAViewer   │  │              │
     │  parse_cmd_   │  │ plot_cmd()   │  │              │
     │  fields()     │  │ plot_all()   │  │              │
     └───────────────┘  └─────────────┘  └──────────────┘
```

## 二、数据结构

### `Frame` (dataclass)

存储一帧解析后的完整信息。

```python
@dataclass
class Frame:
    timestamp: str       # 绝对时间戳 "HH:MM:SS.mmm"（来自串口日志）
    rel_time: float      # 相对于首帧的秒数（用于 X 轴绘图）
    cmd: int             # 功能码 (0x82, 0x8A, 0x8E 等)
    param: int           # 参数字节
    data: bytes          # 原始数据载荷
    checksum_ok: bool    # 校验是否通过
    fields: dict         # 解析后的命名字段 (如 {"Roll": 1.23, "Pitch": -0.45})
```

## 三、协议解析模块

### 3.1 `time_str_to_seconds(time_str) -> float`

将 `"HH:MM:SS.mmm"` 格式转换为当天秒数。

```
伪代码:
    拆分 time_str 为 h, m, s.ms
    返回 h*3600 + m*60 + s + ms/1000
```

### 3.2 `calc_checksum(data) -> int`

计算校验码：对 data 中所有字节做异或，然后取反。

```
伪代码:
    xor_val = 0
    FOR each byte b IN data:
        xor_val = xor_val XOR b
    返回 (~xor_val) AND 0xFF
```

### 3.3 `parse_signed_3byte(sign_byte, high_byte, low_byte) -> float`

解析带符号 3 字节定点数（值已乘 100）。

```
伪代码:
    val = (high_byte << 8) | low_byte
    IF sign_byte == 0x80:
        val = -val
    返回 val / 100.0
```

### 3.4 `parse_unsigned_2byte(high_byte, low_byte) -> int`

解析无符号 2 字节整数。

```
伪代码:
    返回 (high_byte << 8) | low_byte
```

### 3.5 `parse_frame(byte_values, start) -> (Frame | None, int)`

从字节数组的 `start` 位置解析一帧，返回 `(Frame, next_index)`。

```
伪代码:
    IF start + 3 >= len(byte_values):   # 最小帧 head|len|cmd|param 共 4 字节
        返回 (None, start+1)
    IF byte_values[start] != 0x55:    # 帧头不是 0x55
        返回 (None, start+1)

    length = byte_values[start + 1]    # len 字段
    total_len = length + 2             # 总帧长 = head + len内容 + checksum

    IF start + total_len > len(byte_values):
        返回 (None, start+1)

    cmd     = byte_values[start + 2]
    param   = byte_values[start + 3]
    data    = byte_values[start+4 : start+4+(length-3)]
    checksum = byte_values[start + length + 1]
    cs_calc  = calc_checksum(byte_values[start+1 : start+1+length])

    构造 Frame(cmd, param, data, checksum_ok = checksum == cs_calc)
    返回 (frame, start + total_len)
```

### 3.6 `parse_cmd_fields(cmd, data) -> dict`

根据功能码将 data 字节解析为命名字段。

```
伪代码:
    SWITCH cmd:
        CASE 0x82 (角度):
            需要 >= 10 字节（温度可选）
            返回 {Roll, Pitch, Yaw, MagDisturb}
            若 len(data) >= 12: 追加 Temp = data[10..11] / 100.0
        CASE 0x83 (零位设置):
            返回 {ZeroSetStatus}
        CASE 0x84 (零位角度):
            需要 9 字节
            返回 {Roll_base, Pitch_base, Yaw_base}
        CASE 0x87 (报警状态):
            返回 {FaultType}
        CASE 0x8A (地磁):
            需要 11 字节
            返回 {MagNorm, Mx, My, Mz}
        CASE 0x8D (ACK):
            返回 {AckStatus}
        CASE 0x8E (心跳):
            需要 3 字节
            返回 {Counter, IMU_Status, MAG_Status}
        DEFAULT:
            返回 {Raw: hex字符串}
```

### 3.7 `parse_file(file_path) -> list[Frame]`

解析整个 txt 文件。先匹配 0xEE 文本调试行，否则匹配十六进制帧行。

```
伪代码:
    编译正则:
        hex: \[(\d{2}:\d{2}:\d{2}\.\d{3})\]收←◆((?:[0-9A-Fa-f]{2}\s*)+)
        ee : \[(\d{2}:\d{2}:\d{2}\.\d{3})\]...55 00 EE T=<float>  gz_raw=<float>
    初始化 day_offset = 0, base_seconds = None

    FOR each line IN file:
        m_ee = ee正则匹配(line)
        match = (不匹配ee时) hex正则匹配(line)
        IF 都不匹配: CONTINUE

        解析时间戳 → current_seconds
        IF 跨天 (current_seconds < prev_seconds - 12h):
            day_offset += 24h

        IF m_ee:
            构造 Frame(cmd=0xEE, fields={T, gz_raw})   # 文本调试行
            records.append; CONTINUE

        hex_str → byte_values[]
        i = 0
        WHILE i < len(byte_values):
            (frame, next_i) = parse_frame(byte_values, i)
            IF frame 为 None:
                i += 1
            ELSE:
                frame.timestamp = time_str          # 绝对时间
                frame.rel_time = corrected_seconds - base_seconds  # 相对时间
                frame.fields = parse_cmd_fields(frame.cmd, frame.data)
                records.append(frame)
                i = next_i

    返回 records
```

### 3.8 `analyze_temp_gyro(records, ...) -> Figure | None`（0xEE 温度特性分析）

纵坐标温度、横坐标陀螺原始值的特性分析：0.1°C 分箱平均 + 最小二乘拟合。

```
伪代码:
    ee = [cmd==0xEE 且含 T/gz_raw 的帧]
    temps, raws = 提取字段

    # 分箱：中心 c 为 0.1 的倍数，区间 [c-0.05, c+0.05)
    bin_idx = floor((temps + 0.05) / 0.1)
    每箱: count, mean_raw, std_raw

    # 拟合 T = k*raw + b
    (k_w, b_w, r2_w) = _wls_fit(mean_raw, centers, w=count)   # 加权最小二乘（更优）
    (k_o, b_o, r2_o) = _wls_fit(mean_raw, centers, w=1)       # OLS 对照

    打印斜率 k (°C/LSB) 与倒数 (LSB/°C)、R²

    绘图: 原始散点(淡) + 分箱均值(大小∝count) + WLS红线 + OLS绿虚线 + 信息框
    保存 PNG 与分箱 CSV；show 时包装 PureQtWindow 交互显示
```

`_wls_fit(x, y, w)`：加权最小二乘闭式解
`k = Σw(x-x̄w)(y-ȳw) / Σw(x-x̄w)²`，`b = ȳw - k·x̄w`，`R² = 1 - Σw(y-ŷ)²/Σw(y-ȳw)²`。
权重取分箱样本数：样本多的箱均值方差小（∝1/n），WLS 比 OLS 统计上更优。

## 四、交互式可视化模块（Windows 11 稳定版）

> 采用最稳定的交互架构：
> - 单 axes 布局（无多 axes 事件冲突）
> - `button_press_event` 手动检测图例点击切换通道（替代失效的 `pick_event`）
> - `scroll_event` 支持修饰键独立缩放 X/Y 轴
> - `motion_notify_event` 悬停显示绝对时间 + 相对时间 + 各通道坐标

### 4.1 `build_figure(records, cmd, file_name) -> (Figure, dict) | None`

创建交互式波形图（单 axes + 可拖动图例）。

```
伪代码:
    筛选 cmd 对应的帧 → cmd_records
    收集所有字段名 → field_names

    fig, ax = plt.subplots(figsize=(14, 6))    # 单 axes，最稳定

    FOR each field_name:
        提取 y 数据, 分配颜色（Set1+Set2 组合色板，17 种不重复）
        ax.plot(x, y, label=name, color=color)

    legend = ax.legend(loc='upper right', shadow=True, fancybox=True)
    legend.set_draggable(True)    # 图例可拖动移位置

    设置标题（含交互提示）、坐标轴标签、网格

    创建 VOFAViewer 实例 (传入 fig, ax, cmd_records, lines, field_names, legend)
    返回 (fig, {viewer, lines, legend})
```

### 4.2 `VOFAViewer` 类

核心交互控制器，负责图例点击切换、数据光标和滚轮缩放。

#### `__init__(self, fig, ax, records, lines, field_names, legend)`

```
伪代码:
    预计算:
        x           = 各帧 rel_time 数组
        timestamps  = 各帧绝对时间戳列表（HH:MM:SS.mmm）
        y           = 每个通道的值数组（字典）

    # 图例点击切换：建立 legend line → data line 映射
    lined = {}
    FOR legline, name IN zip(legend.get_lines(), field_names):
        lined[legline] = lines[name]

    创建光标元素:
        vline     = 垂直虚线 (axvline, 初始隐藏)
        markers   = 每条曲线一个圆点标记 (plot 'o', 初始隐藏)
        info_text = 左上角信息框 (text, axes坐标系, 字体含 Microsoft YaHei 支持中文)

    平移状态:
        pan_start_x/y, pan_xlim/ylim    # 右键拖拽起始位置和轴范围
        pan_sx, pan_sy                  # 预计算的像素→数据缩放因子

    Blitting 状态:
        blit_bg      = 缓存的背景图（曲线/网格/图例）
        blit_init    = 是否已初始化
        blit_invalid = 背景是否需要重捕

    连接事件:
        button_press_event    → _on_click     # 图例切换 + 平移起始
        motion_notify_event   → _on_move      # 平移 + 数据光标
        scroll_event          → _on_scroll    # 缩放
        button_release_event  → _on_release   # 平移结束
        resize_event          → _on_resize    # 窗口缩放清理
```

#### `_on_legend_click(self, event) -> int | None` — 图例点击检测

```
伪代码:
    获取图例整体包围盒 bbox（display 坐标）
    IF 点击不在 bbox 内: 返回 None

    获取 legend.get_texts()（与 get_lines() 顺序一致）

    # 优先：用各 Text 的 y 范围精确判断点击行
    FOR i, text IN enumerate(texts):
        tb = text.get_window_extent()
        IF tb.y0 - 4 <= event.y <= tb.y1 + 4 且 x 在图例范围内:
            返回 i

    # 回退：按图例总高度均分行高
    row_h = bbox.height / n
    idx = int((bbox.y1 - event.y) / row_h)
    IF 0 <= idx < n: 返回 idx

    返回 None
```

#### `_on_click(self, event)` — 鼠标点击回调

```
伪代码:
    IF event.button != 1: 返回    # 仅左键

    idx = _on_legend_click(event)  # 优先检测图例（处理图例与绘图区重叠）
    IF idx IS NOT None:
        切换对应曲线的 visible 状态
        更新图例线条 alpha（隐藏后 0.3，显示后 1.0）
        canvas.draw()
```

#### `_on_move(self, event)` — 鼠标移动回调（平移 + 数据光标）

```
伪代码:
    # ── 右键拖拽平移（优化：预计算缩放因子，避免每次逆变换） ──
    IF 正在右键拖拽 (pan_start_x 不为 None 且 event.button == 3):
        # 用 _on_click 中预计算的 pan_sx / pan_sy 直接算像素差→数据差
        ddx = (event.x - pan_start_x) * pan_sx
        ddy = -(event.y - pan_start_y) * pan_sy   # 屏幕 Y 向下
        ax.set_xlim(pan_xlim - ddx)
        ax.set_ylim(pan_ylim - ddy)
        draw_idle()    # 触发全图重绘（Qt 自动合并高频请求）
        返回

    # ── 悬停数据光标（blitting 加速） ──
    IF 背景未捕获: _setup_blit()

    x_mouse = _get_data_coords(event)
    IF x_mouse 为 None:
        隐藏光标元素
        restore_region + blit    # 擦除旧光标
        返回

    idx = searchsorted(x, x_mouse)    # O(log n) 查找最近点
    更新 vline, markers, info_text

    # Blitting: 恢复背景 → 绘制光标元素 → blit 到屏幕
    IF 背景失效: _setup_blit()
    restore_region(bg)
    FOR each animated element:
        draw_artist(element)
    blit(ax.bbox)
```

#### `_on_scroll(self, event)` — 滚轮缩放回调（支持修饰键独立缩放）

```
伪代码:
    ax = event.inaxes
    IF ax IS None: 返回
    IF xdata 或 ydata 为 None: 返回

    获取当前坐标轴范围: x_min, x_max, y_min, y_max
    计算宽高: w = x_max - x_min, h = y_max - y_min

    factor = 1.15 (缩小) 或 1/1.15 (放大)

    # 根据修饰键决定缩放哪个轴
    zoom_x = True, zoom_y = True
    IF event.key == 'shift':   zoom_y = False   # 仅 X 轴
    IF event.key == 'control': zoom_x = False   # 仅 Y 轴

    IF zoom_x: w = w * factor
    IF zoom_y: h = h * factor

    计算鼠标在坐标轴中的相对位置:
        curXpos = (curx - x_min) / (x_max - x_min)
        curYpos = (cury - y_min) / (y_max - y_min)

    以鼠标位置为缩放中心:
        IF zoom_x: ax.set_xlim(curx - w*curXpos, curx - w*curXpos + w)
        IF zoom_y: ax.set_ylim(cury - h*curYpos, cury - h*curYpos + h)

    调用 fig.canvas.draw_idle() 刷新
```

## 五、数据导出模块

### `export_data(records, output_dir)`

按功能码分组导出 CSV 和 Excel。

```
伪代码:
    收集所有不同的 cmd 值
    FOR each cmd:
        筛选 cmd 对应的帧
        构造行列表:
            每行 = {
```

## 八、已确认的 Bug 清单及修复记录

| 编号 | 问题 | 根因 | 最终修复方案 |
|------|------|------|-------------|
| 1 | 通道选择无效 | `pick_event` 在 qtagg 后端完全不触发（0 次） | 改用 `button_press_event` + 手动检测图例区域（通过 `legend.get_texts()` 位置判断） |
| 2 | 滚轮缩放无法独立控制 X/Y | 原始实现仅支持 X+Y 同步缩放 | 添加修饰键支持：Shift+滚轮仅缩放 X 轴，Ctrl+滚轮仅缩放 Y 轴 |
| 3 | 信息框中文显示为方块 | info_text 字体设为 Consolas 不支持 CJK | 字体列表首位改为 Microsoft YaHei |
| 4 | 缺少绝对时间显示 | 信息框仅显示相对时间 | 信息框首行显示绝对时间（HH:MM:SS.mmm），导出也增加绝对时间列 |
| 5 | VSCode 中交互功能全部失效 | VSCode 注入 `MPLBACKEND=inline`，导致 `plt.show()` 不阻塞、事件循环不启动 | 清除 `MPLBACKEND` 环境变量 + 使用纯 `PureQtWindow` 包装 `FigureCanvasQTAgg` + `QApplication.exec_()` 直接管理事件循环 |
| 6 | 缩放/平移后出现光标残影 | blitting 的 `_setup_blit()` 在 `draw_idle()` 尚未执行时就捕获背景，旧光标被烘焙进背景图 | 平移/缩放开始时立即 `_hide_cursor()` 并标记 `_blit_invalid`，确保下次 `_setup_blit()` 捕获的是无光标的干净背景 |
| 7 | 右键拖拽平移卡顿 | 每次 `motion_notify_event` 都调用 `transData.inverted().transform()` 做坐标逆变换，开销大；渲染顶点数过多 | ① 在 `_on_click` 中预计算像素→数据缩放因子，平移时简化为一次乘法；② 平移期间临时将 `path.simplify_threshold` 提高到 1.0（最大简化），释放后恢复；③ 降低抽取目标 (3000→1500) |
| 8 | 程序刚启动时出现残影 | Qt 在 Windows 11 下默认会清除窗口背景再绘制 canvas，导致首帧出现闪烁/残影 | 设置 `canvas.setAttribute(Qt.WA_OpaquePaintEvent, True)` 禁止 Qt 清除背景；`show()` 后调用 `draw()` + `processEvents()` 确保首帧渲染完成 |
| 9 | Y 轴平移方向反转 | 预计算缩放因子优化时 `ddy` 多取了一次反号：`ddy = -(dy) * sy`，而公式 `new_ylim = pan_ylim - ddy` 已通过减法处理方向，导致双重取反 | 去掉 `ddy` 计算中的负号：`ddy = (event.y - pan_start_y) * pan_sy` |
| 10 | 0x82 无温度帧解析失败（温度可选） | `parse_cmd_fields` 对 0x82 强制要求 `len(data) >= 12`。固件在 `communicate_protocol.h` 中注释掉温度字节后，0x82 帧 data 仅 10 字节，所有帧被拒导致角度数据全部丢失 | 温度改为可选项：`len(data) >= 10` 解析 Roll/Pitch/Yaw/MagDisturb；仅 `len(data) >= 12` 时额外解析 `Temp`。含/不含温度帧可混用，缺 Temp 自动以 NaN 留空 |

### 架构演进历史

1. **V1**: CheckButtons → 点击无效（Qt5Agg 事件冲突）
2. **V2**: 自定义 add_axes 面板 → 点击仍无效（多 axes 事件竞争）
3. **V3**: 单 axes + `pick_event` legend picking → `pick_event` 在 qtagg 下完全不触发
